A complete, 10-15 page formal academic documentation is prepared and saved right in this repository. It is optimized with print CSS stylesheets, page breaks, and official institution headings so you can print it out directly on paper or save as PDF.

Key Formulations in the Report:

Performance Score = (Final_Marks × 0.35) + (Attendance × 0.15) + (Study_Score × 0.10) + (Assignment_Score × 0.10) + (Quiz_Average × 0.10) + (Practical_Score × 0.10) + (Internal_Marks × 0.10)

Performance Gap = Individual Performance Score − Department Average Score
